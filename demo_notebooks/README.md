# Demo Notebooks

These notebooks are designed to help you work with the sample Digital Earth Normalised Radar Backscatter product for Sentinel-1 from Geoscience Australia. 
We are providing two data collections:
* Collection 0 has a wide range of spatial and temporal data, but immature metadata
* Collection 1 has a smaller range of spatial and temporal data, but more mature metadata

We recommend trying Collection 1 first, and if there is no data for your use case, then try Collection 0. 
Tutorial notebooks are provided for both collections:
* [tutorial_c0](tutorial_c0) - this folder contains a series of numbered notebooks that take you through product information, how to load data, and how to post-process the data for analysis for Collection 0.
* [tutorial_c1](tutorial_c1) - this folder contains a series of numbered notebooks that take you through product information, how to load data, and how to post-process the data for analysis for Collection 1.

In addition to the tutorials, there are the [extended_examples](extended_examples) notebooks - additional notebooks that demonstrate extended visualisation tasks, more complex data loading, or analysis.
